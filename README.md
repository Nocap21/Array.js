# JavaScript Practice

A JavaScript practice repository focused on learning and strengthening **core JavaScript concepts** through examples, coding problems, and hands-on practice.

##  Topics Covered

### 🔹 Functions & Methods — `fandm.js`

Practice related to JavaScript functions and methods, including:

* Functions
* Parameters and arguments
* Return values
* Function expressions
* Arrow functions
* Methods
* Calling and using functions

### 🔹 Arrays — `array.js`

Contains various **array-based coding problems with solutions**.

Topics include:

* Creating and accessing arrays
* Adding and removing elements
* Updating array elements
* Array operations
* Array methods
* Array-based problem solving

### 🔹 Asynchronous JavaScript — `app.js`

Covers the progression of asynchronous JavaScript concepts:

```text
Callbacks
    ↓
Callback Hell
    ↓
Promises
    ↓
Promise Chaining
    ↓
Async / Await
```

Topics include:

* Callback functions
* Callback Hell
* Promises
* Promise chaining
* `async`
* `await`
* Handling asynchronous operations

### 🔹 Classes & Objects — `classandobj.js`

Practice with JavaScript **objects and classes**.

Topics include:

* Objects
* Object properties
* Object methods
* Creating objects
* Classes
* Class properties
* Class methods
* Creating objects from classes

### 🔹 Classes & Constructors — `classandcon.js`

Practice with **JavaScript classes and constructors**.

Topics include:

* Classes
* Constructors
* Class properties
* Constructor parameters
* Initializing object properties
* Creating objects using classes
* Class methods

### 🔹 Inheritance & `super` — `inherindsuper.js`

Practice with JavaScript classes and inheritance.

Topics include:

* Parent and child classes
* Inheritance
* `extends`
* `super`
* Calling parent constructors
* Calling parent class methods
* Reusing properties and methods through inheritance

### 🔹 DOM

Practice with the **Document Object Model (DOM)**.

Topics include:

* Selecting HTML elements
* Changing HTML content
* Modifying elements
* Working with element properties
* Connecting JavaScript with HTML

### 🔹 Events

Practice with JavaScript event handling.

Topics include:

* Events
* Event listeners
* Click events
* User interactions
* Handling browser events

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Nocap21/JavaScript-Practice.git
```

### 2. Open the project

Open the `JavaScript-Practice` folder in **Visual Studio Code**.

### 3. Run the project

Open `index.html` in your browser.

For JavaScript output, open:

```text
Browser → Developer Tools → Console
```
